# 合并门禁验证任务

## 目标与范围

验证实验室测试 Fork 的 PR 协作流程：CI 失败时应阻止合并，修复后应满足必需检查。
本任务仅修改此协作文档，不运行算法、训练、硬件或真实数据处理，不自动合并 PR。

## 基线与依据

从用户已合并初始化配置的 main 提交
`0b8bf0e000712ef58ae3ce3c5efccd3bca9ec7da` 建立独立测试分支。
中央规范来源为 `57cbc84535ec43729ea171a58d7b078b403cf2b4`。
使用真实 `lab-ci` 运行和 GitHub 服务端 PR 状态作为证据，不创建伪造的成功检查。

## 验收方式

1. 读取生效规则，确认 main 要求 PR 和 GitHub Actions 提供的 `lab-ci` 成功。
2. 用重复一级标题触发 MD025，核对失败运行及服务端合并阻断状态。
3. 将重复标题改为二级标题，核对新 SHA 的检查成功和合并条件恢复。
4. 请求 Codex 原生 GitHub 审核，分别记录审核结果、覆盖 SHA 和未验证事项。

## 验证记录

实际 SHA、CI run URL、规则集 ID、失败/修复结果和 AI 审核证据由验收报告记录。
这份任务描述本身不代表远程门禁或 AI 审核已验证成功。
